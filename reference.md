## Key Animation Patterns

| Pattern | Description | Used On |
|---------|-------------|---------|
| **GSAP + ScrollTrigger** | Scroll-driven reveals, parallax, timeline sequences | Nearly all product pages |
| **Canvas frame sequences** | Hundreds of images painted to canvas synced to scroll | AirPods Pro, MacBook Air |
| **Three.js / R3F** | 3D product models with rotation, color switching | iPhone, MacBook, Vision Pro |
| **Locomotive Scroll** | Smooth inertia-based scrolling | Vision Pro landing page |
| **Framer Motion** | Declarative component-level animations | Page transitions, UI elements |
| **CSS view-timeline** | Native CSS scroll-linked animations (no JS) | Modern implementations |
| **Sticky + video sync** | Video playback controlled by scroll position | iPhone X, Mac Pro |
| **SplitText** | Character/word-level text reveal animations | Headlines, hero sections |

## Recommended Learning Path

1. **[adrianhajdin/iphone](https://github.com/adrianhajdin/iphone)** — Start here. Most complete reference with 3D + GSAP + React.
2. **CSS-Tricks AirPods tutorial** — Understand the canvas frame sequence technique.
3. **IHateTomatoes Mac Pro deconstruction** — Learn how Apple structures their animation timelines.
4. **Builder.io view-timeline** — Modern CSS-only approach for simpler scroll effects.
5. **Wael Yasmina Three.js series** — Deep dive into 3D product visualization.
